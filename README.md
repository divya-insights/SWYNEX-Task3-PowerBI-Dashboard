# SWYNEX Task 3 – Interactive Power BI Dashboard

## Project Overview

This project presents an interactive Retail Sales Analysis Dashboard created using Microsoft Power BI as part of the SWYNEX internship tasks.

## Objectives

- Analyze retail sales performance.

- Compare sales across product categories.

- Understand payment method preferences.

- Compare online and in-store sales.

- Explore sales trends over time.

## Dashboard Features

- **KPI Cards:** Total Sales, Total Transactions, and Total Quantity Sold.

- **Sales by Category:** Compares sales across product categories.

- **Sales by Payment Method:** Compares Cash, Digital Wallet, and Credit Card sales.

- **Sales by Location:** Compares online and in-store sales.

- **Sales Trend:** Shows sales over time.

- **Interactive Filters:** Category, date, and location slicers.

- **Discount Analysis:** Compares sales for transactions with and without discounts.

## Tools Used

- Microsoft Power BI

- Retail Sales Dataset

- Data Cleaning and Visualization
